# pair-wise-yf-46 国际新闻直播编排与突发插播控制台

源提示词摘要：面向导播、主编、字幕和演播室岗位的直播串联单，维护新闻片、连线、嘉宾、口播和广告；支持时长重算、硬时间风险、突发插播、角色权限、操作历史、一键撤回和断网应急队列。

## 固定编排规则

- 直播窗口固定 **08:00–09:00（60 分钟）**，**08:30 广告（3 分钟）不能挪、不能改、不能跳过**。
- 导播突发插播时，只评估**插播点之后、同一段（广告前/广告后）内未播的普通条目**（新闻片/连线/嘉宾/口播，含已插入的突发）；已播出内容与广告保持原位。
- 腾挪策略：先**压缩**（每条下限 1 分钟，从前往后），不够再从尾部**整条移走**；被移走条目进入「待补播清单」。
- 后面未播普通条目的可腾总量不足时**直接拒绝**，并明确列出**还差几分钟**，状态不发生任何变化。
- 接受预案后：时长与顺序变化立即生效，**后续时间全部重算**，广告始终锚定 08:30，收播始终为 09:00。
- **主编**可以新增/修改未播普通内容（时长不得顶到广告或越过 09:00）；**字幕、演播室**的越权修改一律拒绝，错误提示并在状态中留痕（denials）。
- 所有写操作进入操作历史快照（含待补播清单），支持一键撤回完整回滚。
